# Parenting Companion — clickable prototype

A shared day planner for parents and their 9–12-year-old child. Planner first, not a tracker; location is included and always visible to the child.

**Live prototype:** open `index.html` (GitHub Pages link in the repository's About section).

- 22 screens: parent mode (“Today”) and child mode (“My day”), Armenian and English
- Built in Claude Design on the project design system; every button works
- Plain static files: no server and no build step. `support.js` is the Claude Design runtime that renders the `.dc.html` pages
